**Federated Agentic Protocol (FAP)** — my final-year research. A verifier-LLM layer that sits between a planning agent and its tools and breaks the *confused-deputy* chain that prompt injection depends on. The verifier never sees raw user input — only structured metadata — and returns a constrained-JSON verdict in **sub-5ms** on the hot path. Local **Phi-3 Mini** via Ollama, YAML policy engine (Pydantic), tamper-evident hash-chain audit log, one-line `@IntentGate` integration. Packaging as an open-source Python SDK.
