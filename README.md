## 🧬 About

I build systems that have to be trusted — the kind where a wrong answer isn't a bug, it's a breach.

- 🛡️ **AI Security** — My core focus: teaching autonomous LLM agents to respect boundaries. My final-year research is an **Intent-Aware Reference Monitor** — security middleware that sits between an agent and its tools and validates every action against the user's actual intent before it executes.

- 🎓 **BS Software Engineering** @ COMSATS University — final year.

**Open To:** AI security research collaboration · Software engineering internships · Open-source contribution · Freelance product builds

## 🚀 Featured Projects

<details>
<summary><b>🛡️ Intent-Aware Reference Monitor — Security Middleware for LLM Agents</b></summary>
<br/>

Security middleware that sits between an autonomous LLM agent and its tools, extracting the user's true intent and validating **every** tool call against it before execution — so a hijacked agent can't act outside the boundaries of what the user actually asked for.

| | |
|:--|:--|
| **Stack** | Python · FastAPI · LLM APIs · Agent tool-calling / MCP |
| **Scale** | Mediates the full agent action stream — every tool call passes through the monitor, zero-bypass by design |
| **Performance** | Inline policy decisions engineered to add minimal latency to the agent loop |
| **Security** | Deny-by-default policy engine · intent extraction · defense against indirect prompt injection and agent hijacking |
| **Impact** | Final Year Project @ COMSATS — targets the open research gap between agent capability and agent trust |
| **Repository** | 🔒 Private (active research) — [reach out for details](mailto:talhaiqbal1121@gmail.com) |

Autonomous agents are given real power — file systems, email, payments — with no guard between "what the model decided" and "what the user meant." This project closes that gap with a classical security primitive (the reference monitor) rebuilt for the LLM era.

</details>
